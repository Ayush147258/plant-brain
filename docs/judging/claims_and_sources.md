# Claims And Sources Checklist

This file prevents the deck and landing page from making claims that judges can challenge.

## Claims From The Challenge Brief

The user-provided challenge statement includes these statistics:

| Claim | Current Source Status | Use In Deck? |
|---|---|---|
| Professionals in asset-intensive industries spend 35% of working hours searching, clarifying, or recreating documents. | Challenge brief cites a 2024 McKinsey global survey. Exact public URL/PDF still needs confirmation unless the official hackathon brief is attached. | Yes if attributed to challenge brief; stronger if exact source is added. |
| Large Indian plants operate across 7 to 12 disconnected document systems. | Challenge brief cites NASSCOM-EY. Exact report/page still needs confirmation. | Yes if attributed to challenge brief; stronger if exact source is added. |
| Fragmentation contributes to 18-22% of unplanned downtime events in Indian heavy industry. | Challenge brief cites BIS Research. Exact report/page still needs confirmation. | Yes if attributed to challenge brief; stronger if exact source is added. |
| 25% of experienced Indian industrial engineers/operators will retire within the next decade. | Challenge brief gives this estimate. Exact source still needs confirmation. | Use carefully as "challenge brief estimate" unless independently sourced. |

## Recommended Safe Wording

Use this wording in the deck if exact source PDFs are not attached:

"The official challenge brief highlights severe knowledge fragmentation: 35% of work time lost to search/recreation, 7-12 disconnected document systems per large Indian plant, 18-22% downtime contribution from fragmented knowledge, and a coming retirement-driven knowledge cliff. PlantBrain directly targets those failure modes."

## Claims PlantBrain Can Prove Directly

These should be proven with screenshots or CSV benchmark results:

- Time-to-answer for benchmark questions.
- Number of document types ingested in the demo.
- Number of chunks indexed.
- Number of graph nodes/relationships extracted.
- Number of compliance findings returned.
- Whether answers include citations and confidence caveats.

## Do Not Claim Without Proof

Avoid these unless you collect evidence:

- "94% accuracy" unless you score benchmark answers.
- "0.9 second average response" unless measured on the final setup.
- "80% compliance gaps detected" unless validated against a labeled rule set.
- "Works on every document format" unless each listed format has a passing test/demo.
